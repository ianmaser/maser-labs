## Phase 1 — Design System / Tokens / Primitives

**Goal:** Color tokens, reusable UI primitives, typography scale.

**What was done:**
- Color tokens defined in `globals.css` as CSS variables + Tailwind v4 `@theme inline`:
  - `--bg-base: #05060A`, `--bg-elevated: #0F1117`
  - `--text-primary: #F5F7FA`, `--text-muted: #9CA3B0`
  - `--accent-cyan: #22D3EE`, `--accent-purple: #8B5CF6`
  - `--border-subtle: #1C1F27`
- Typography scale added to `globals.css`: h1/h2/h3 with `clamp()` fluid sizing, body at 16px/1.7 line-height
- Built 5 UI primitives in `components/ui/`:
  - **GlowContainer** — radial glow wrapper (cyan/purple/both, subtle/medium/strong intensity). Children made optional to support background-only usage.
  - **Button** — primary (gradient cyan→purple) and secondary (dark + border) variants, default and lg sizes, hover glow/scale, focus ring, supports `href` prop for link behavior
  - **Card** — rounded, bg-elevated, border-subtle, optional glow shadow, hover border transition
  - **SectionHeading** — eyebrow label (small, uppercase, accent colored) + large headline, centered or left-aligned
  - **GhostWordmark** — huge faded "MASER LABS" text at 3% opacity, responsive sizing
- Built kitchen sink test page at `/kitchen-sink` rendering all primitives
- Verified all primitives render correctly on desktop

**Decisions made:**
- Skipped shadcn/ui — forms are simple enough to build by hand, and shadcn's styling opinions would fight the custom dark/glow design system. Added as "Maybe" item in TODO.md for potential v2 revisit.
- Ghost wordmark initially too large at `clamp(4rem,15vw,12rem)`, later reduced to `clamp(3rem,10vw,7rem)`

## Phase 3 — Page Sections

**Goal:** Build all 11 page sections, compose into landing page.

**What was done:**
- Built 11 section components in `components/sections/`:
  1. **Nav** (`"use client"`) — fixed sticky nav, logo left, desktop links + gradient CTA right, mobile hamburger menu with slide-down panel
  2. **Hero** — full-height section with GlowContainer (both colors), placeholder circle for showpiece graphic, h1 headline, subline, IntakeFormTop, two CTAs
  3. **TrustStrip** — credibility line + tech logos in muted uppercase
  4. **Services** — SectionHeading + 4 Cards with lucide icons (Globe, Bot, Palette, BarChart3), hover states
  5. **Portfolio** (`"use client"`) — SectionHeading (purple accent) + 3 project cards with GlowContainer, placeholder screenshot areas, expandable tech details toggle
  6. **About** — two-column grid: portrait placeholder with GlowContainer (purple) on left, SectionHeading + story + stats block on right
  7. **Process** — SectionHeading + 4-column grid with numbered circles, titles, descriptions
  8. **Pricing** — GlowContainer (cyan, subtle) + SectionHeading + range signal text + CTA button
  9. **LeadMagnet** — GlowContainer (purple, medium) + SectionHeading + description + CTA button
  10. **Contact** — SectionHeading + IntakeFormBottom
  11. **Footer** — ghost wordmark background, copyright, LinkedIn/GitHub SVG icons

- Built 2 form components in `components/forms/`:
  - **IntakeFormTop** (`"use client"`) — "What do you want to build?" + email + Go button. Posts to `/api/lead` with `source: "hero_hook"`. Success/error states.
  - **IntakeFormBottom** (`"use client"`) — full qualifying form: name, email, business name, business type, service interest (dropdown), budget range (dropdown), timeline (dropdown), project details (textarea). Posts to `/api/lead` with `source: "bottom_form"`. Success confirmation message.

- Composed all sections into `app/page.tsx` in scroll order

**Issues encountered & fixed:**
- `lucide-react` v1.28 removed brand icons (`Linkedin`, `Github`). Fixed by using inline SVG icons instead.
- `GlowContainer` required `children` prop but Hero used it without children (as background layer). Fixed by making `children` optional.
- Ghost wordmark in footer was too large/prominent, obscuring footer content. Reduced from `clamp(4rem,15vw,12rem)` to `clamp(3rem,10vw,7rem)`.
- Section spacing between Process/Pricing/LeadMagnet was excessive. Reduced Pricing and LeadMagnet padding from `py-24` to `py-16`.

**Verify:** Full page builds clean, deployed to Vercel, all sections rendering correctly.
