# Session 03 — 2026-08-26

## Summary

Visual polish pass to get the site ready for v1 before public viewing. Focused on breaking up flat dark space, threading the hero's visual DNA through the rest of the site, and adding scroll-triggered animations.

---

## Fixes

### Ghost Wordmark Opacity (Footer)
- The "MASER LABS" ghost text in the footer was rendering at full opacity, covering footer content
- Root cause: Tailwind's opacity modifier (`text-text-primary/[0.03]`) doesn't work with hex colors registered via `@theme inline` — the token doesn't decompose for alpha injection
- Fix: replaced Tailwind class with inline `style={{ color: 'rgba(245, 247, 250, 0.03)' }}`
- Also added `z-0` / `z-10` layering to ensure footer content renders above the wordmark

## Visual Enhancements

### 1. Section Background Glows
Added `GlowContainer` wraps to the three flattest sections:
- **Services** — cyan, subtle intensity
- **Process** — purple, subtle intensity
- **Contact** — dual cyan+purple, subtle intensity

### 2. Line Grid Texture
- Created a `.dot-grid` CSS class in `globals.css` — originally dot-based, switched to a line grid pattern at the user's request
- 1px lines at 3.5% opacity on a 28px grid, echoing the hero's wireframe geometry
- Applied to **Services** and **Contact** sections

### 3. Gradient Divider Lines
- Created `GradientDivider` component — a 1px horizontal line with `linear-gradient` from transparent → cyan → purple → transparent
- Placed between five section transitions: Services/Portfolio, Portfolio/About, About/Process, Process/Pricing, LeadMagnet/Contact
- Skipped between Pricing/LeadMagnet (both are glowed CTA sections that flow together)

### 4. Accent-Colored Stats
- Changed About section stat values ("5+", "Citibank, Verizon", "10+") from white to cyan (`#22D3EE`)
- Used inline style due to the same Tailwind token opacity issue

### 5. Enhanced Card Hover Glow
- Added `.card-glow` CSS class with a two-layer cyan bloom on hover: 30px tight glow + 60px ambient glow
- Border brightens to cyan on hover
- Pure CSS (no client component needed), applied via the `Card` component

### 6. Process Step Glow Rings
- Added box-shadow glow to the step number circles: 12px tight bloom + 30px ambient
- Cyan border and text via inline styles (Tailwind token workaround)

### 7. Rotating Gradient Button Border
- Added `.btn-orbit` CSS animation system — a conic-gradient (cyan → purple → cyan) that rotates around the button border on hover
- `::before` pseudo-element holds the rotating gradient, `::after` masks the inner fill
- Primary buttons: gradient inner fill. Secondary buttons: dark inner fill
- 3s rotation loop, fades in on hover via opacity transition
- Button children wrapped in `<span className="relative z-10">` to sit above pseudo-elements

### 8. Scroll-Triggered Animations
Created reusable animation components using framer-motion:

**Components** (`components/ui/ScrollReveal.tsx`):
- `ScrollReveal` — fade + directional slide (up/left/right), `whileInView`, fires once
- `StaggerContainer` + `StaggerItem` — parent triggers staggered reveals on children

**Applied to:**
- **Service cards** — staggered fade-up, 120ms between cards
- **Portfolio cards** — staggered fade-up, 150ms between cards
- **Process steps** — sequential fade-up left-to-right, 150ms stagger
- **About section** — portrait slides from left, text from right, stats stagger in with 300ms delay
- **Section headings** — subtle 24px fade-up via `SectionHeading` component (disabled on About heading since it's already inside a directional reveal)

All animations respect `prefers-reduced-motion`.

## Decisions Made

- Tailwind's opacity modifier on custom `@theme` hex tokens is broken — use inline styles with explicit rgba values as a workaround throughout the project
- Line grid chosen over dot grid for texture — better echo of hero wireframe geometry
- Animations are deliberate and sparse: stagger reveals on card groups, directional slides on the About split layout, fade-up on headings. No animation on Pricing/LeadMagnet/Footer to keep it calm
- All hover effects (cards, buttons) use pure CSS to avoid unnecessary client component boundaries
